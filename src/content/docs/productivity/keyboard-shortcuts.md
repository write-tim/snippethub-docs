SnippetHub is built for keyboard productivity. Use these shortcuts to navigate, search, and manage snippets at maximum speed.

## Global Shortcuts (Any Webpage)

| Action | Mac Shortcut | Windows / Linux Shortcut |
| :--- | :--- | :--- |
| **Open Command Palette** | `⌘ + Shift + P` | `Ctrl + Shift + P` |
| **Address Bar Omnibox** | `⌘ + L` &rarr; type `snip ` | `Ctrl + L` &rarr; type `snip ` |

## Side Panel Navigation & Search

| Action | Shortcut |
| :--- | :--- |
| **Focus Search Bar** | `/` or `⌘ + F` / `Ctrl + F` |
| **Command Palette** | `⌘ + K` / `Ctrl + K` |
| **New Snippet** | `⌘ + N` / `Ctrl + N` or `N` (when not typing) |
| **New Folder** | `⌘ + Shift + N` / `Ctrl + Shift + N` |
| **Expand / Collapse All** | `⌘ + A` / `Ctrl + A` |
| **Switch to Folder 1–9** | `1`, `2`, `3`, ..., `9` |
| **View All Folders** | `0` |
| **Navigate Snippet Cards** | `ArrowUp` / `ArrowDown` |
| **Show Shortcuts Dialog** | `?` |

## Actions on Selected Snippet

When a snippet card is highlighted using the arrow keys (and you are not focused in an input field):

| Key | Action |
| :---: | :--- |
| `Enter` or `C` | **Copy** snippet to clipboard |
| `I` | **Insert** snippet directly into active webpage field |
| `E` | **Edit** snippet |
| `D` | **Duplicate** snippet |
| `F` | Toggle **Favorite** |
| `P` | Toggle **Pin** to top |
| `Delete` / `Backspace` | **Delete** snippet |
