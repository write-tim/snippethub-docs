SnippetHub deeply integrates with Chrome's native clipboard and context menu APIs, allowing you to capture ideas on the fly and deploy formatted content with zero friction.

## Multi-Format Clipboard Copy & Paste

When you click **Copy** or press `Enter` / `C` on a snippet card, SnippetHub copies your snippet in your chosen default format—or lets you override the format on the fly:

```text
SnippetHub Clipboard Engine
       │
       ├── ✨ Rich Text (Dual-MIME) ──► Google Docs, MS Word, Gmail, Outlook, Notion, Slack
       ├── 📄 Plain Text            ──► Unstyled text/plain (strips all HTML & Markdown tags)
       ├── 📝 Markdown              ──► Clean GitHub-Flavored Markdown (.md)
       └── 🌐 HTML                  ──► Raw HTML markup (</>)
```

### Multi-Format Copy & Paste Options

- **Default Copy Format Selector**: Use the format indicator (`✨` / `📄` / `📝` / `🌐` / `⚡`) in the list header bar or the **Copy Format** setting in the Avatar menu to set your global default (`Rich Text`, `Plain Text`, `Markdown`, `HTML`, or `Auto (Mode)`).
- **Right-Click "Copy As" Mini-Menu**: Right-click any snippet card's Copy button (or Quick Look's Copy button) to immediately copy as **Rich Text**, **Plain Text**, **Markdown**, or **HTML**—or choose from the card's `⋮` menu.
- **Paste as New Snippet (`⌘V` / `Ctrl+V`)**: Click the split dropdown next to the **+ Add** button (or press `⌘V` / `Ctrl+V` when browsing snippets) to paste your clipboard directly into a new snippet as **Rich Text**, **Plain Text**, **Markdown**, or **HTML**.
- **In-Editor Copy & Paste Dropdowns**: Inside the snippet editor header bar, use the **Copy ▾** and **Paste ▾** menus to copy or paste as **Rich Text**, **Plain Text**, **Markdown**, or **HTML**.

For complete details on authoring in **Visual WYSIWYG**, **Markdown**, or **Raw HTML** modes and the destination app behavior matrix, see the [Rich Text, HTML & Markdown Formatting guide](/features/rich-text-and-code/).
:::

## Right-Click Context Menu Integration

Whenever you encounter useful code, an insightful explanation, or an email response you want to reuse:

<Steps>
1. Highlight the text on any webpage.
2. Right-click the selected text.
3. Select **Save selection to SnippetHub** from Chrome's context menu.
</Steps>

### Configurable Context Menu Actions

You can choose what happens when you trigger the context menu item:

- **Auto-Save (Default)**: Instantly saves the selected text to your SnippetHub library in the background. A confirmation notification confirms the save, keeping your reading or research uninterrupted.
- **Open Form**: Automatically opens the SnippetHub side panel with the highlighted text pre-filled in the editor, allowing you to immediately add a custom title, assign a folder, and choose tags.

#### How to Switch the Context Menu Action

<Steps>
1. Open the SnippetHub side panel.
2. Click your avatar icon in the top-right corner.
3. Locate the **Right-Click** dropdown under *Customization*.
4. Choose either `Auto-Save` or `Open Form`.
</Steps>

## One-Click Copy vs Direct In-Page Insertion

SnippetHub gives you two distinct options to deploy snippets:

| Method | How It Works | Best Used For |
| :--- | :--- | :--- |
| **Copy to Clipboard** | Resolves dynamic placeholders and loads both HTML and plaintext to your system clipboard (`⌘V` / `Ctrl+V`). | Any desktop application, external app, Google Docs, or cross-browser paste. |
| **Insert into Active Field** | Synthesizes native input events to inject the snippet directly into the focused field without overwriting your clipboard. | Web forms, comment boxes, search fields, or when preserving existing clipboard content. |
