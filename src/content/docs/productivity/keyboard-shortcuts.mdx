SnippetHub is built for keyboard productivity. Use these shortcuts to navigate, search, organize, and expand snippets at maximum speed.

## In-Page Text Expansion (Any Webpage)

| Action | Shortcut / Keystroke |
| :--- | :--- |
| **Trigger Auto-Expansion** | Type your configured trigger key (`default: ;`), enter the snippet **Keyword**, and press `Space`, `Enter`, or `Tab`. |
| **Trigger Autocomplete Pill** | Type trigger key + 1+ letters (e.g. `;s`, `/me`) to summon the floating suggestion pill. |
| **Cycle Pill Suggestions** | `↑` / `↓` arrow keys |
| **Insert Selected Suggestion** | `Tab` or `Enter` |
| **Dismiss Suggestion Pill** | `Esc` or click outside |
| **Change Expansion Trigger** | Configurable in avatar menu: `;`, `/`, `!`, `,`, `@`, `#`, `:`, or `~`. |

## Global Browser Shortcuts

| Action | Mac Shortcut | Windows / Linux Shortcut |
| :--- | :--- | :--- |
| **Open Command Palette** | `⌘ + Shift + P` | `Ctrl + Shift + P` |
| **Address Bar Omnibox** | `⌘ + L` &rarr; type `snip ` | `Ctrl + L` &rarr; type `snip ` |

## Side Panel Navigation & Search

| Action | Shortcut |
| :--- | :--- |
| **Focus Search Bar** | `/` or `⌘ + F` / `Ctrl + F` |
| **Clear Search / Dismiss Suggestions** | `Esc` |
| **Open Command Palette** | `⌘ + K` / `Ctrl + K` |
| **New Snippet Form** | `⌘ + N` / `Ctrl + N` or `N` (when not typing) |
| **New Folder Dialog** | `⌘ + Shift + N` / `Ctrl + Shift + N` |
| **Expand / Collapse All Cards** | `⌘ + A` / `Ctrl + A` |
| **Switch to Folder 1–9** | `1`, `2`, `3`, ..., `9` |
| **View All Folders** | `0` |
| **Navigate Snippet Cards** | `ArrowUp` / `ArrowDown` |
| **Open Keyboard Shortcuts Dialog** | `?` |

## Card Actions (When Snippet Is Highlighted)

When a snippet card is highlighted using the arrow keys:

| Key | Action |
| :---: | :--- |
| `Space` | **Quick Look Preview** modal (macOS style; `↑`/`↓` navigates, `C` copies, `I` inserts, `E` edits) |
| `Enter` or `C` | **Copy** snippet to clipboard (multi-MIME HTML + plaintext) |
| `I` | **Insert** snippet directly into active web input |
| `E` | **Edit** snippet in side panel form |
| `D` | **Duplicate** snippet |
| `F` | Toggle **Favorite** |
| `P` | Toggle **Pin** to top |
| `Delete` / `Backspace` | **Delete** snippet |
