SnippetHub supports both styled rich text and syntax-highlighted code snippets.

## Rich Text Editing (Quill)

The built-in Quill editor allows you to format your snippets with:
- **Headings & Hierarchy**: H1, H2, and subheadings.
- **Text Styling**: Bold, italic, underline, strikethrough.
- **Lists**: Ordered numbered lists and bullet points.
- **Links**: Clickable URLs.
- **Blockquotes**: Stylized callout quotes for documentation or emails.

When copied or inserted into email clients (Gmail, Outlook) or rich web text areas (Notion, Google Docs), the HTML formatting is faithfully preserved.

## Code Highlighting (Highlight.js)

When writing code snippets, SnippetHub automatically formats and syntax-highlights code blocks using **Highlight.js** with GitHub-Dark styling.

Supported languages include:
- JavaScript / TypeScript
- Python
- HTML & CSS
- JSON & YAML
- SQL
- Shell / Bash scripts
- Markdown
