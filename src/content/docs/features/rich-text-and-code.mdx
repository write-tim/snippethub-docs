SnippetHub is built to handle everything from complex customer support emails with clickable links to syntax-highlighted code blocks and raw Markdown templates. 

To support diverse workflows, SnippetHub features **three specialized editor modes** paired with an intelligent **dual-MIME clipboard engine**.

---

## The Three Editor Modes

When creating or editing a snippet in the side panel or pop-out window, you can toggle between three authoring environments using the mode switcher tabs above the editor:

```text
┌─────────────────┬─────────────────┬─────────────────┐
│ Visual WYSIWYG  │    Markdown     │    Raw HTML     │
└─────────────────┴─────────────────┴─────────────────┘
```

### 1. Visual WYSIWYG Mode (Default)

Powered by the **Quill** rich text engine, Visual mode provides a familiar word-processor experience:

- **Hierarchy & Headings**: H1, H2, and subheadings.
- **Styling**: Bold (`⌘B`), Italic (`⌘I`), Underline (`⌘U`), and Strikethrough.
- **Lists**: Bulleted lists and ordered numbered lists.
- **Links**: Clickable hyperlinks that automatically enforce `target="_blank"` and `rel="noopener noreferrer"` to protect against Reverse Tabnabbing.
- **Blockquotes**: Stylized callout quotes for email replies or documentation notes.
- **Code Blocks**: Formatted monospaced blocks for short terminal commands or code snippets.

### 2. Markdown Mode

If you live in **Obsidian**, **Notion**, **GitHub**, or static site generators, Markdown mode allows you to compose snippets using standard GitHub-Flavored Markdown (GFM):

```markdown
# Meeting Notes: {{date}}

- **Client**: {{client:Company Name}}
- **Status**: [Active](https://example.com)

```bash
docker compose up -d
```
```

- **Live Mode Switching**: Toggling between Markdown and Visual mode automatically converts between Markdown syntax and rendered HTML using SnippetHub's built-in converter (`markdownToHtml` and `htmlToMarkdown`).
- **Markdown Preservation**: When you save in Markdown mode, the snippet retains its pure Markdown structure when inserted into standard text areas, code files, and terminals.

### 3. Raw HTML Mode

For advanced users and email designers who require exact control over tags and inline styles:

- **Source Inspection**: View and edit the exact HTML markup produced by the rich text editor.
- **Custom Tags**: Author tables (`<table>`, `<tr>`, `<td>`), semantic dividers (`<hr>`), and inline styled spans.
- **Built-in Sanitization**: Any HTML authored or pasted into Raw HTML mode is automatically verified against SnippetHub's strict tag allowlist to ensure safety and prevent broken layouts.

## Syntax Highlighting (Highlight.js)

When previewing snippets in the list or viewing them in **Quick Look (`Spacebar`)**, SnippetHub automatically detects and formats code blocks using **Highlight.js** with GitHub-Dark styling.

Supported languages include:
- **Web & Scripting**: JavaScript, TypeScript, HTML, CSS, PHP
- **Backend & Data**: Python, SQL, Go, Rust, Java, C/C++
- **DevOps & Config**: Shell/Bash, Dockerfile, YAML, JSON
- **Documentation**: Markdown, Plain Text

## How Copy & Paste Works (The Dual-MIME Pipeline)

When you click **Copy** on any snippet card or press <kbd>C</kbd> / <kbd>Enter</kbd> in Quick Look, SnippetHub utilizes the modern **Async Clipboard API** with dual MIME payloads:

```text
SnippetHub Copy Action
       │
       ├── text/html   ──► Consumed by rich text editors
       │                   (Gmail, Outlook, Docs, Word, Notion, Slack)
       │
       └── text/plain  ──► Consumed by plain text and code environments
                           (VS Code, Terminal, Textarea, Markdown files)
```

### Destination App Behavior Matrix

| Target Application | MIME Type Consumed | What Gets Pasted |
| :--- | :---: | :--- |
| **Google Docs & Microsoft Word** | `text/html` | Formatted bold/italic text, headings, clickable links, styled tables, and colors. |
| **Gmail & Outlook Web** | `text/html` | Complete rich text email layout with working links and bullet points. |
| **Slack, Teams & Discord** | `text/html` / `text/plain` | Rich message formatting including bold, quotes, and monospaced code. |
| **VS Code, Sublime, IDEs** | `text/plain` | Clean plain text or literal Markdown syntax without any unwanted `<p>` or `<div>` tags. |
| **macOS Terminal / Linux Bash** | `text/plain` | Pure executable CLI commands without formatting artifacts. |
| **Obsidian / Logseq / Notion** | `text/html` or `text/plain` | Formatted blocks or Markdown syntax depending on editor paste settings. |

## How In-Page Text Expansion Behaves

When expanding snippets via keywords (e.g. typing `;sig` followed by Space) or using the **Insert Directly (`I`)** button:

1. **Rich ContentEditable Areas** (Gmail, Outlook, Zendesk, Notion, Google Docs):
   - SnippetHub synthesizes native DOM insertion (`insertHTML`) to paste the formatted HTML directly at your cursor.
   - Any dynamic placeholders (`{{date}}`, `{{clipboard}}`) are resolved prior to injection.
2. **Standard Text Inputs & Textareas** (`<input type="text">`, `<textarea>`):
   - If the snippet was saved in **Markdown** or **HTML** mode, SnippetHub inserts the exact literal Markdown or HTML code.
   - If the snippet was authored in **Visual WYSIWYG** mode, SnippetHub cleanly strips all HTML tags and inserts clean plain text.

## Tips for Copying & Pasting

:::tip[Pasting as Plain Text When Desired]
If you are in a rich text application (like Google Docs or Gmail) but want to paste **without** formatting, use your operating system's native paste-as-plain-text shortcut:
- **Mac**: <kbd>⌘ + Shift + Option + V</kbd>
- **Windows / Linux**: <kbd>Ctrl + Shift + V</kbd>
:::

:::tip[Exporting Full Markdown Vaults]
If you want to migrate your entire snippet library into Obsidian or Notion as individual `.md` files with YAML frontmatter, use the **Export Vault (.zip)** feature under the avatar menu. See the [Cloud Sync & Vault Export guide](/account-sync/cloud-sync-and-backup/) for details.
:::
