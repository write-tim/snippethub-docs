Chrome's address bar (the Omnibox) can be used as a direct search interface for your SnippetHub library.

## Using the Omnibox

<Steps>
1. Click Chrome's URL / address bar (or press `⌘L` on Mac / `Ctrl+L` on Windows).
2. Type `snip` and press `Space` or `Tab`.
3. The address bar turns into a SnippetHub search box.
4. Type your query. Suggested snippets appear in real-time in the dropdown autocomplete list.
5. Select a snippet and press `Enter`.
6. SnippetHub resolves any dynamic variables (such as dates) and copies the snippet to your clipboard, presenting a confirmation notification.
</Steps>
